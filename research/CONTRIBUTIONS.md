# Core Contributions

The primary contribution of this research is the **integration** of previously isolated parameters into a coherent planning architecture. Rather than relying on singular vectors (like gap analysis or market demand alone), the system mathematically synthesizes six distinct domains:

1. **Student-specific skill gap**: Identifying precisely what the user currently lacks.
2. **Career-specific skill importance**: Valuing skills based on their technical relevance to a target role.
3. **Observed job-market demand**: Contextualizing skill value against real-world employability factors.
4. **Prerequisite constraints**: Ensuring chronological and logical feasibility of the learning path.
5. **Learning cost/budget**: Recognizing the finite temporal and cognitive limits of the learner.
6. **Closed-loop state-based re-planning**: Introducing dynamic feedback mechanisms to alter the plan in response to internal (student learning) and external (market shift) state changes.

By fusing these components, the research delivers a unified, reproducible pathway generation framework.
