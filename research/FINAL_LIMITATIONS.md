# FINAL SYSTEM LIMITATIONS

Open scientific engineering mandates an unfiltered exposure of structural system limitations blocking complete practical utility limits. 

## Academic Admittance of Fallibility
1. **Linear Human Complexity Abstractions**: Computing `Learning Cost` as a flattened numerical target boundary assumes static absorption rates. Actual humans encounter complex burnout loops, localized geographic constraints, financial walls, and non-uniform cognitive decay (The Forgetting Curve) that PathForge does not presently trace algorithmically. 
2. **The "Cold Start" Dataset Assumption**: Extracting pure Jaccard outputs measuring collaborative filter distances inherently lacks rich temporal interaction traces usually available to SOTA Netflix/Amazon recommendation grids.
3. **Macro-Economic Smoothing Fallibility**: External job markets fluctuate violently outside static indexing models. Relying purely on historical `Market Demand` parameters risks isolating users inside obsolete correlation domains if statistical models degrade across chronological phases.
4. **Greedy Traversal Overlap**: Because the system prioritizes $Weight/Cost$ ratios tracking immediate maximum utility (Greedy Node Optimization), it structurally misses extended path shortcuts potentially available to algorithms processing total NP-Hard global temporal trees entirely rather than stepwise closures.
