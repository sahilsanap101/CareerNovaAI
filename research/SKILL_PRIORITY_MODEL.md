# Skill Priority Model Framework

## Overview
The B2 Skill Priority Model constructs a strict prioritization heap of unmastered skills required for a student $u$'s target career $c$. Rather than randomly selecting deficits, the model statistically quantifies the learning urgency of each node as a function of the user's proficiency gap, the target career's specific domain weighting, and real-world market demand execution parameters.

## Core Rules
1. **Prerequisite Decoupling**: Theoretical priority scores DO NOT ingest artificial penalties based on prerequisite topologies. Prerequisites are rigid state-driven constraints processed autonomously by the DAG. 
2. **Deterministic Inputs**: The calculated output is reproducible for identical constraint matrices.
3. **Traceable Outputs**: Output maps bind provenance and evidence objects directly to the output skill tracking struct, preventing data hallucinations.

## Evaluative Integration
The resulting ordered subset generated by this algorithm is consumed by the final Roadmap Optimization planner. The priority weight specifies *what* is critical, while the Formal Skill DAG restricts *when* it can be learned.
