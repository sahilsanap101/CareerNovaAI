# PathForge Research Reproducibility Package

Welcome to the official repository supporting the publication evaluation of the PathForge adaptive educational trajectory planner. This module provides mathematically decoupled environments guaranteeing the isolated repetition, validation, and computational expansion of our claimed findings.

## Academic Guarantees
1. **Zero Black-Box Reliance**: Generative LLM interfaces (AIOS/Gemini) are strictly severed from the computational evaluation logic. 
2. **Fixed Environments**: All executed configurations serialize exact dependencies, models, and node inputs natively into cryptographic logs ensuring topological deterministic parity over simulations ($N=300$).
3. **No Metric Cherry-Picking**: Scripts automatically generate raw `Cohen's d` matrices dumping comprehensive JSON/CSV data across `A0` through `A6` paradigms without hiding algorithmic prerequisite crashes.

## Quickstart
Review the `REPRODUCIBILITY.md` and `ENVIRONMENT.md` specifications to instantiate the local execution baseline, then utilize the unified experiment CLI to yield isolated outputs into your `/results` directory.
