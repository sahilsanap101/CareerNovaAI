# Core Novelty Claim & Research Boundaries

To establish a clear novelty boundary suitable for IEEE research, we explicitly differentiate this framework from common existing implementations patternized in the EdTech and HR-Tech spaces.

## What This Contribution is NOT
The novelty of this research is **NOT**:
- Merely career recommendation (which is heavily researched).
- Merely skill-gap analysis (which is a standard set-difference operation).
- Merely semantic matching of resumes to job descriptions.
- Merely an LLM chatbot wrapper for career advice.
- Merely an ontological knowledge graph of skills.
- Merely a dynamic roadmap UI interface.
- Merely an automated job recommendation feed.

## The Novelty Boundary
The core novelty of this research lies in the **simultaneous integration** of multidimensional constraints into a unified, reproducible closed-loop planning framework.

Specifically, the framework combines:
1. Computation of student-specific skill gaps.
2. Weighting of career-specific skill importance.
3. Ingestion of observed job-market skill demand.
4. Adherence to strict topological prerequisite constraints.
5. Optimization against a finite learning cost/budget threshold.
6. Execution of a state-based, closed-loop re-planning mechanism.

By synthesizing these elements, the research advances the literature in educational pathway generation by moving from isolated, static heuristics (the baseline) toward a cohesive, dynamically resilient planning algorithm.
