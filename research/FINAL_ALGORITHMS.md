# FINAL ALGORITHMS PROTOCOL

PathForge is officially anchored around a strict progression from Classical Heuristics to Graph-Constrained Priority Maximizations.

## The B0-B4 Model Stack
*   **E1 Baseline (Collaborative Filtering Benchmark)**: Simulates state-of-the-art classical recommender logic purely through Boolean matching distance formulas (Jaccard Index Arrays). Lacks any chronological constraints. 
*   **B0 Heuristic Baseline (Legacy BYSER)**: Evaluates match percentages mathematically, failing to rank required chronologies or market variables.
*   **B1 Market-Aware Model**: Injects real `MarketDemand` and `CareerWeight` utility equations multiplying node relevance values accurately. 
*   **B2 Skill Priority Model**: Instantiates the $Priority(n) = (Gap_{n} \times MarketWeight_{n} \times CareerRank_{n}) / LearningCost_n$ algorithmic parameter tracking explicit learning constraints.
*   **B3 Constrained Topological Planner**: Validates the priority equations against rigid Directed Acyclic Graph (DAG) structures ensuring mathematically that no target is prescribed before logical dependencies are satisfied.
*   **B4 Closed-Loop Adaptation Strategy**: Tracks stochastic volatility natively dynamically logging timeline diff calculations whenever external market forces fluctuate metrics.
